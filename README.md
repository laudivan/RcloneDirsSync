# RcloneDirsSync

A bash script that automates management and synchronization of directories with Rclone's `bisync` command.

With this app you can sync your local directories with one on cloud, like Google Drive, Dropbox, OneDrive, S3, etc, without install official client apps. Also, you can schedule syncs with cron avoiding memory resident applications.

I hope You'll enjoy it!

## Prerequisites

**Install Rclone** from [https://rclone.org/downloads/](https://rclone.org/downloads/)
